# AI Usage Log — ABTalks Vibe Hackathon

## Project
ABTalks — 60-Day Coding Challenge Redesign

## Team
MCBOYS

## AI-Assisted Development

This project was developed using AI-assisted coding and design workflows.

### Prompt 1 — Project Structure

Designed a mobile-first ABTalks redesign with:
- Landing page
- Student dashboard
- Challenge day page
- Reusable React components
- Mock JSON data

### Prompt 2 — Landing Page

Create a modern mobile-first landing page for a 60-day coding
challenge for Indian college students. Focus on consistency,
daily progress, GitHub proof, LinkedIn visibility and recruiter
discoverability.

### Prompt 3 — Student Dashboard

Create a student dashboard showing:
- Current streak
- Overall completion
- Today's challenge
- Achievements
- Student ranking
- Progress indicators

### Prompt 4 — Challenge Day

Create a challenge detail page showing:
- Day number
- Challenge title
- Description
- Mission checklist
- Progress
- GitHub submission
- LinkedIn submission

### Prompt 5 — UI/UX

Use a dark, modern, mobile-first interface with:
- Purple accent colors
- Clear typography
- Responsive cards
- Strong visual hierarchy
- 390px mobile viewport compatibility

### Prompt 6 — React Architecture

Organize the application using reusable React components
and separate page components for:
- Landing
- Dashboard
- Challenge Day

Use mock data instead of authentication or a production database.

## AI Tools Used

AI was used for:
- UI/UX ideation
- Component structure
- React implementation assistance
- CSS styling assistance
- Debugging
- Deployment troubleshooting

## Human Direction

The team reviewed, modified and tested the generated implementation,
selected the final design direction, and integrated the components
into the submitted project.

## Validation

The application was tested locally using Vite and the required
routes were verified during development.
